
# TrybeTunes 🎵

**TrybeTunes** é uma aplicação simples de músicas que permite aos usuários:  
- Pesquisar músicas baseadas no nome do artista, da música ou do álbum.  
- Criar playlists personalizadas e marcar músicas como favoritas.  

Este projeto é uma demonstração de 30 segundos de músicas e foi desenvolvido para aprender integração com APIs externas e criação de perfis de usuário.

## 🛠️ Funcionalidades

- **Busca de músicas**: Encontre músicas pelo nome do artista, música ou álbum usando a API do iTunes.  
- **Playlists personalizadas**: Crie playlists e salve-as localmente.  
- **Músicas favoritas**: Marque músicas como favoritas e gerencie sua lista.  
- **LocalStorage**: Salvamento das informações diretamente no navegador.  

## 🚀 Tecnologias Utilizadas

- **JavaScript**  
- **React**  
- **Redux**  
- **APIs externas** (Exemplo: iTunes API)  

## 🧑‍💻 Instalação

1. Clone o repositório:  
   git clone https://github.com/Gzuuu/project-trybetunes.git

2. Navegue até a pasta do projeto:  
   cd project-trybetunes

3. Instale as dependências:  
   npm install

4. Inicie o projeto:  
   npm start

## 📂 Observações

- Todos os arquivos modificados estão localizados dentro da pasta `src/`.  
- A parte de CSS não foi um foco neste projeto e, portanto, não foi modificada.  

## 📚 Principais Aprendizados

- Consumo de **APIs externas** para busca de dados (iTunes API).  
- Criação de perfis de usuários e gerenciamento de dados utilizando **LocalStorage**.  
- Uso de **Redux** para gerenciar o estado da aplicação.  
- Estruturação e componentização de aplicações com **React**.
